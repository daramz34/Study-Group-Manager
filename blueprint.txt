User
├── id
├── username (unique)
├── email (unique)
├── hashed_password
├── created_at

Group
├── id
├── name
├── subject (e.g. "MAT201 - Linear Algebra")
├── description
├── invite_code (unique, auto-generated)
├── created_by (FK → User)
├── created_at

GroupMember
├── id
├── group_id (FK → Group)
├── user_id (FK → User)
├── role (enum: admin, member)
├── joined_at

StudyGoal
├── id
├── group_id (FK → Group)
├── title
├── description
├── topic_content (Text — what to study, used by Gemini)
├── week_number (int)
├── day_number (int, optional)
├── deadline (Date)
├── created_by (FK → User)
├── created_at

GoalCompletion
├── id
├── goal_id (FK → StudyGoal)
├── user_id (FK → User)
├── completed_at

Quiz
├── id
├── goal_id (FK → StudyGoal)
├── user_id (FK → User)
├── questions (Text — JSON string from Gemini)
├── answers (Text — JSON string from user)
├── score (Float, nullable — filled after grading)
├── feedback (Text — JSON string from Gemini)
├── created_at
├── graded_at (DateTime, nullable)

Streak
├── id
├── user_id (FK → User)
├── group_id (FK → Group)
├── current_streak (int, default 0)
├── longest_streak (int, default 0)
├── last_active_date (Date, nullable)
├── updated_at

PointTransaction
├── id
├── user_id (FK → User)
├── group_id (FK → Group)
├── amount (int — can be negative)
├── reason (String — e.g. "quiz_score_9", "weekly_bonus")
├── created_at

Resource
├── id
├── group_id (FK → Group)
├── uploaded_by (FK → User)
├── title
├── description (nullable)
├── file_url (String — Cloudinary URL)
├── file_type (String — pdf, image, doc)
├── created_at


User → Group (created_by) — one user creates many groups
User → GroupMember — one user belongs to many groups
User → Quiz — one user takes many quizzes
User → PointTransaction — one user has many point transactions
User → Streak — one user has many streaks (one per group)

Group → GroupMember — one group has many members
Group → StudyGoal — one group has many goals
Group → Resource — one group has many resources
Group → Streak — one group has many member streaks
Group → PointTransaction — one group has many point transactions

StudyGoal → GoalCompletion — one goal completed by many users
StudyGoal → Quiz — one goal has many quiz attempts (one per user)


Delete Group → delete GroupMember, StudyGoal, Resource, 
               Streak, PointTransaction
Delete StudyGoal → delete GoalCompletion, Quiz
Delete User → delete GroupMember, Quiz, GoalCompletion,
              Streak, PointTransaction






AUTH:
UserCreate     → username, email, password
UserResponse   → id, username, email, created_at
TokenResponse  → access_token, token_type

GROUPS:
GroupCreate    → name, subject, description
GroupResponse  → id, name, subject, description, invite_code,
                 created_by, created_at
GroupUpdate    → name, description (both optional)

GROUP MEMBERS:
GroupMemberResponse → id, group_id, user_id, role, joined_at
JoinGroupRequest    → invite_code

STUDY GOALS:
GoalCreate     → title, description, topic_content, 
                 week_number, day_number, deadline
GoalResponse   → id, group_id, title, description, 
                 topic_content, week_number, day_number,
                 deadline, created_by, created_at
GoalUpdate     → title, description, topic_content,
                 deadline (all optional)

GOAL COMPLETION:
GoalCompletionResponse → id, goal_id, user_id, completed_at

QUIZ:
QuizResponse      → id, goal_id, user_id, questions, 
                    answers, score, feedback, 
                    created_at, graded_at
SubmitAnswers     → answers (list of dicts)

STREAK:
StreakResponse    → id, user_id, group_id, current_streak,
                    longest_streak, last_active_date, updated_at

POINTS:
PointTransactionResponse → id, user_id, group_id, amount,
                           reason, created_at

LEADERBOARD:
LeaderboardEntry  → user_id, username, total_points,
                    current_streak, quizzes_completed
LeaderboardResponse → group_id, week_number, entries: list[LeaderboardEntry]

RESOURCES:
ResourceResponse  → id, group_id, uploaded_by, title,
                    description, file_url, file_type, created_at

DASHBOARD:
DashboardResponse → groups: list[GroupResponse],
                    pending_goals: list[GoalResponse],
                    upcoming_deadlines: list[GoalResponse],
                    total_points: int,
                    current_streak: int




USER:
get_user_by_username(db, username)
get_user_by_email(db, email)
create_user(db, user: UserCreate)
authenticate_user(db, username, password)

GROUPS:
create_group(db, group: GroupCreate, current_user) 
    → generate invite_code
    → create group
    → auto-add creator as admin in GroupMember
    → create Streak record for creator
get_my_groups(db, current_user)
get_group_by_id(db, group_id)
update_group(db, group_id, update: GroupUpdate, current_user)
delete_group(db, group_id, current_user)
join_group(db, invite_code, current_user)
    → find group by invite_code
    → check not already member
    → add as GroupMember with role=member
    → create Streak record
leave_group(db, group_id, current_user)
get_group_members(db, group_id)


GOALS (admin only for create/update/delete):
create_goal(db, group_id, goal: GoalCreate, current_user)
    → check current_user is admin of group
get_group_goals(db, group_id, week_number=None)
get_goal_by_id(db, goal_id)
update_goal(db, goal_id, update: GoalUpdate, current_user)
delete_goal(db, goal_id, current_user)

QUIZ:
start_quiz(db, goal_id, current_user)
    → check goal exists
    → check no existing quiz for this user+goal today
    → call gemini to generate questions
    → save Quiz with questions, no answers yet
    → return quiz
submit_quiz(db, quiz_id, answers: list[str], current_user)
    → get quiz
    → check belongs to current_user
    → check not already graded
    → call gemini to grade answers
    → save answers, score, feedback, graded_at
    → award points based on score
    → update streak
    → create GoalCompletion if score >= 5
    → return graded quiz

POINTS:
add_points(db, user_id, group_id, amount, reason)
    → create PointTransaction
get_total_points(db, user_id, group_id)
    → sum all PointTransaction.amount for user in group

STREAK:
get_or_create_streak(db, user_id, group_id)
update_streak(db, user_id, group_id, passed: bool)
    → passed=True (score>=5): streak+1, update last_active
    → passed=False: streak resets to 0

LEADERBOARD:
get_group_leaderboard(db, group_id, week_number=None)
    → for each member get total_points, streak, quizzes_completed
    → sort by total_points descending
    → add rank number
    → return LeaderboardResponse

RESOURCES:
upload_resource(db, group_id, resource: ResourceCreate, current_user)
get_group_resources(db, group_id)
delete_resource(db, resource_id, current_user)

DASHBOARD:
get_dashboard(db, current_user)
    → get all groups user is member of
    → get pending goals (not yet completed by user)
    → get upcoming deadlines (next 7 days)
    → get total points across all groups
    → get current streak across all groups

USER STATS:
get_user_stats(db, user_id, group_id)
    → total_points in group
    → current_streak in group
    → longest_streak in group
    → quizzes_taken in group
    → avg_score across quizzes
    → rank in group leaderboard
    → goals_completed in group


services/gemini.py:

generate_quiz_questions(topic_content: str) -> list[dict]
    prompt → "generate 5 questions based on this topic"
    returns → [{"id":1, "type":"factual", "question":"..."}]

grade_quiz_answers(topic_content, questions, answers) -> dict
    prompt → "grade these answers against this topic"
    returns → {
        "results": [{"question_id":1, "score":2, "feedback":"..."}],
        "total_score": 8,
        "summary": "Strong on recall..."
    }

generate_weekly_digest(group_name, member_stats) -> str
    prompt → "summarize this group's weekly activity"
    returns → plain text summary for email
